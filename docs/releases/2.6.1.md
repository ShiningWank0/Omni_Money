## 主な変更

- サーバーの Echo を 4.16.6 に更新し、プロキシと静的ファイル配信のパス処理に関する脆弱性を修正しました。 [#502](https://github.com/ShiningWank0/Omni_Money/pull/502)
- 画面の Vue を 3.5.46 に、グラフ表示で使う vue-chartjs を 5.3.7 に更新しました。 [#503](https://github.com/ShiningWank0/Omni_Money/pull/503) · [#504](https://github.com/ShiningWank0/Omni_Money/pull/504)
- Windows のビルド環境に MSYS2 公式の libexpat 2.11.0-1 を取り込みました。Docker のビルド環境では BuildKit、runc、containerd に修正版の依存関係を反映しました。 [#540](https://github.com/ShiningWank0/Omni_Money/pull/540) · [#541](https://github.com/ShiningWank0/Omni_Money/pull/541) · [#557](https://github.com/ShiningWank0/Omni_Money/pull/557)
- CI に、取引金額の計算範囲と Unix の秘密情報ファイルのアクセス権を検査する工程を追加しました。 [#524](https://github.com/ShiningWank0/Omni_Money/pull/524)

## 対応環境

macOS は **13 Ventura 以降**で、Apple Silicon 版と Intel 版を提供します。Windows・Linux 向けのデスクトップ版と、Linux amd64・arm64 向けの Docker イメージを提供します。

- Wails の開発用ブラウザの再接続と終了処理を追跡しています。 [#299](https://github.com/ShiningWank0/Omni_Money/issues/299)
- フロントエンドのビルドツールで使う picomatch の暫定修正を維持し、公式版への切り替えを追跡しています。 [#348](https://github.com/ShiningWank0/Omni_Money/issues/348)
