## 対応環境と互換性

macOSは**13 Ventura以降**です。既に採用している[Go 1.27の要件](https://go.dev/doc/go1.27#darwin)に合わせ、appメタデータとlink設定を統一しています。

Windows・Linuxでは実配布物のnative UIを起動し、保管庫作成・解錠・再起動・正常終了を検証しています。Windowsでは実Go IPCを介した取引の作成・更新・正確な残高・再起動後の保持・削除と、ロック中の読取拒否も検証します。

macOS両CPUでは配布ZIPの署名・DB自己診断に加え、実ウィンドウの生成と起動後の生存、所有processとwindowの終了を確認します。macOSの全UI操作とnative file picker自体のUI操作は自動化の対象外です。
